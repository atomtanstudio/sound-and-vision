# Photographic composition references

These three Sound/Vision-generated artworks are internal quality references for
the song director. They are not choices presented to the user and do not determine
a song's subject automatically. The director must use the supplied genre, era,
lyrics and creative notes to choose and describe a new composition.

- `console.png`: original American Soviets photographic console.
- `dream.png`: original The Number I Still Know pearlescent listening machine.
- `boombox.png`: Next at Rucker v004, the large black-and-chrome box requested by the user.

Only these generated assets are bundled. The external period research photographs
and the user's photograph are not distributed with the application.
